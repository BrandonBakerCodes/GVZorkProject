<h1>Zork</h1>
<p>Zork was known for being one of the first games with natural language processing. In this game, you are able to tell the computer a sentence to get one step closer to the end goal. This recreation of Zork was a project created by Brandon Baker and Bailey Compton as a project for Grand Valley State University's programming languages class. This game was written in C++ with a make file to help compile the game file.</p>

<h2>Key Features</h2>
<ol>
  <li>Various locations to explore.</li>
  <li>Items can be collected, eaten, and used.</li>
  <li>NPCs to interact with.</li>
</ol>

<h2>Instructions</h2>
<ol>
  <li>Clone Repository</li>
  <li>Run "sudo apt install make" and "sudo apt install clang" in project root directory.</li>
  <li>Run "make" in project root directory.</li>
  <li>Run "./game" to start the game.</li>
  <li>Run "help" to see list of valid commands.</li>
</ol>
